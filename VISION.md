# Vision

The goal of this project is to modernize dotProject for PHP 8.5 and MariaDB 11 while preserving its original workflow, ACL model and user experience.

## Principles

- Preserve the original ACL model.
- Preserve the original workflow.
- Preserve the original project hierarchy.
- Prefer standards over proprietary integrations.
- Keep the core lightweight.
- Avoid unnecessary feature creep.

## Non-Goals

- Rewriting the ACL system.
- Building a file management platform.
- Building a calendar server.
- Replacing the classic dotProject workflow.
